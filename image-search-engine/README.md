
# PixelFind — Image Search Engine

A responsive image search application built with HTML, CSS, and JavaScript, using the Unsplash REST API.

## Features
- Search photographs by keyword
- Debounced live search
- Responsive image grid
- Image lightbox preview
- Load more results
- Loading, empty, and error states
- Photographer attribution and source links

## Technologies
- HTML5
- CSS3
- JavaScript
- Fetch API
- Unsplash API

## Setup
1. Create an Unsplash developer application.
2. Copy the Access Key.
3. Replace `YOUR_UNSPLASH_ACCESS_KEY` in `js/script.js`.
4. Open `index.html` using VS Code Live Server or another local web server.

## API and Security
This frontend demo uses a browser-visible API key. Do not put secret keys in public repositories. For a public production application, route API requests through a backend or use an approved key-restriction strategy. Follow Unsplash API guidelines and attribution requirements.
