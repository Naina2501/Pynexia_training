
# Glass Morphism Digital Clock

A responsive digital clock built using HTML, CSS, and JavaScript.

## Features
- Live digital clock with seconds
- 12-hour and 24-hour format toggle
- Analog second-hand rotation
- Frosted-glass effect using CSS backdrop-filter
- Responsive layout

## Technologies
- HTML5
- CSS3
- JavaScript

## How to Run
Open `index.html` in a modern web browser.
