
# Wedding Planner Website

A responsive wedding and event planning portfolio website built with HTML, CSS, and JavaScript.

## Features
- Responsive navigation
- Hero and about sections
- Wedding planning services
- Portfolio gallery
- Skills and education section
- Contact enquiry form with basic client-side handling
- Mobile-friendly layout

## Technologies
- HTML5
- CSS3
- JavaScript
- VS Code

## Run Locally
Open `index.html` in a modern web browser.

## Customization
Replace the sample business name, project photos, statistics, skills, and education details with accurate information. The contact form is a front-end demo and does not send messages to a server.
