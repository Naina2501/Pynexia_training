# Task Manager

A simple and user-friendly Task Manager web application built with HTML, CSS, and JavaScript. It helps users organize daily tasks, track progress, and manage their work efficiently.

## Features

- Add and manage tasks
- Edit and delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks by status
- Set task priorities
- Add due dates
- Track task completion progress
- Save tasks in browser local storage
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Data Storage

Tasks are stored in the browser's Local Storage. Data is saved in the browser used to access the application and is not automatically synchronized between devices.
